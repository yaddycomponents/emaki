# @emaki/core

The Emaki engine — design tokens, motion presets, and the timeline bridge shared by the Framer (preview) and Remotion (render) adapters.

Part of **[Emaki](https://github.com/yaddycomponents/emaki)** — local-first motion films from a `deck.json`. AI comes in through MCP; Emaki never calls a model or stores a key.

## Install

```bash
npm i @emaki/core@beta
```
